# Trust handoff contract

For meaningful work, report only the sections that add value:

## Outcome

What now works.

## Evidence

The strongest direct or observable evidence.

## Verification

Commands and checks that ran, including failures that remain relevant.

## Independent review

Verdict and meaningful findings. State when no independent review was warranted.

## Review changes

Important changes caused by review.

## Unexpected findings

MEANINGFUL, DECISION, or CRITICAL discoveries. Omit when none occurred.

## Remaining uncertainty

Anything material that is still not established.

## Your action

DELEGATE, REVIEW, or UNDERSTAND. For REVIEW or UNDERSTAND, give exact code areas and reasons, and state what can be delegated.

## Git provenance

List checkpoint commits and the command that isolates review-induced changes. Omit when no commits were authorized or useful.
